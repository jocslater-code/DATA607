3.1 Raw Data Construction Create a source data file that captures all information from the original dataset while preserving its wide (untidy) structure. This file serves as the unmodified input to your transformation pipeline.

Create a .csv file containing all information from the original dataset. Preserve the original wide format — do not tidy the data at this stage. Alternative: store the dataset in a relational database instead of a flat .csv file.

3.2 Data Import and Tidying Primary Grading Component

Import your data into R and apply a reproducible sequence of tidyr and dplyr operations. Your code must demonstrate each of the following transformations explicitly:

  • Reshape from wide to tidy (long) format
  • Normalize variable structure
  • Rename variables to follow a consistent naming convention
  • Address missing or inconsistent values with documented handling decisions

The following example illustrates a minimal tidying pipeline using pivot_longer():

Code 
# Import raw data
raw_data <- read.csv("data/dataset_wide.csv")

# Reshape to tidy format
tidy_data <- raw_data |>
  pivot_longer(
    cols      = -id,
    names_to  = "variable",
    values_to = "value"
  ) |>
  rename_with(tolower) |>
  drop_na()

3.3 Analysis Perform the specific analysis requested in the original Discussion 5A item for each dataset. All analysis must operate on the tidy dataset produced in Step 3.2 — do not analyze the raw wide-format data directly.

Include the following outputs as appropriate for each analysis: - Summary tables with clearly labeled columns and units - Visualizations with axis labels, titles, and legends - A brief narrative interpreting each result in context

  1. Documentation and Reproducibility All code and narrative must be written in a Quarto Markdown (.Qmd) file. Quarto extends the R Markdown ecosystem with improved cross-referencing, theming, and multi-format output — see the quarto.org documentation if you are new to the format.

Your .Qmd file must document each of the following in order:

  • Data source — where the dataset originated and how it was obtained
  • Data structure before tidying — column names, row count, and a representative sample
  • Transformation steps — commented, executable code with explanations of each decision
  • Analytical methods — a description of the statistical or summarization approach applied
  • Conclusions — a substantive interpretation of results with reference to specific values
