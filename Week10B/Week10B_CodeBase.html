Question 1: Which birth month is the most popular for novel laureates?

The question of most popular birth month is answered simply by extracting birth dates, converting the birth date into a date object, and tallying those results up by month.

Code 
# Extract birth dates, convert, and grab the month
month_counts <- nobel_df %>%
  filter(!is.na(birth.date)) %>% # remove the records where there is no birthdate
  mutate(
    # Strings to Date objects 
    birth_date_parsed = ymd(birth.date, quiet = TRUE),
    # Extract month label 
    birth_month = month(birth_date_parsed, label = TRUE, abbr = FALSE)
  ) %>%
  filter(!is.na(birth_month)) %>%
  count(birth_month, name = "count") %>%
  arrange(desc(count))

#print(month_counts)
Code 
# Bar chart of birthdays by month
ggplot(month_counts, aes(x = reorder(birth_month, count), y = count, fill = count)) +
  geom_col(show.legend = FALSE) +
  coord_flip() +
  geom_text(aes(label = count), hjust = -0.2, fontface = "bold") +
  ylim(0, max(month_counts$count) * 1.15) +
  labs(
    title = "Most Popular Birth Months of Nobel Laureates",
    x = "Month",
    y = "Number of Laureates"
  ) +
  theme_minimal(base_size = 13) +
  theme(
    plot.title = element_text(face = "bold", hjust = 0.5),
    plot.subtitle = element_text(hjust = 0.5),
    panel.grid.major.y = element_blank()
  )

The results are generally in line with the modern trend. An article from Baby Center claims that for 2023, the most popular birth months were August, July, October, September, June, May, January, March, November, December, April, February.

Question 2: What is the breakdown of male and female laureates over time?

Although the question of gender breakdown of Nobel laureates is rather trivial, I took this opportunity to explore animated plots. First I filter and clean the data. Then I calculate the yearly cumulative sum for men and women. The bar plot of this data is animated to allow us to track the ratio of male and female laureates over time.

Code 
gender_df <- nobel_df %>%
  unnest(nobelPrizes, names_sep = "_") %>%
  transmute(
    gender = gender,
    year = as.numeric(nobelPrizes_awardYear)
  )

gender_df_clean <- gender_df %>%
  filter(gender %in% c("male", "female")) %>%
  mutate(gender = str_to_title(gender))

yearly_count <- gender_df_clean %>%
  group_by(year, gender) %>%
  summarise(count = n(), .groups = "drop")

min_year <- min(gender_df_clean$year, na.rm = TRUE)
max_year <- max(gender_df_clean$year, na.rm = TRUE)
cumulative_df <- yearly_count %>%
  complete(year = full_seq(c(min_year, max_year), 1), gender = c("Female", "Male"), fill = list(count = 0)) %>%
  group_by(gender) %>%
  mutate(cumulative_count = cumsum(count)) %>%
  ungroup()
Code 
# Animate bar chart
p <- plot_ly(
  cumulative_df,
  x = ~gender,
  y = ~cumulative_count,
  color = ~gender,
  colors = c("Female" = "#E74C3C", "Male" = "#3498DB"),
  frame = ~year,
  type = "bar"
) %>%
  layout(
    title = "Cumulative Nobel Laureates by Gender Over Time",
    xaxis = list(title = "Gender"),
    yaxis = list(title = "Total Laureates"),
    barmode = "group"
  ) %>%
  animation_opts(
    frame = 100,       
    transition = 0,    
    redraw = TRUE
  )
p

It’s obvious that men dominated the early years of the Nobel prize. It isn’t until the mid 20th century that you can discern any thickness to the female bar plot. Although more recent years have seen more diversity, the prize still heavily favors men and the early years of the award ensure a wildly unbalanced graph.

Question 3: Which countries have the most laureates that remain for their entire life?

To answer this question, I needed to clean and filter for birth country and death country, then subselect the laureates for whom those are the same country. After tallying these up, we can see which country has the most expat laureates.

Code 
lifecycle_countries <- nobel_df %>%
  # Select and clean birth and death country columns
  select(
    name = knownName.en,
    birth_country = birth.place.countryNow.en,
    death_country = death.place.countryNow.en
  ) 

# Remove cases where birth country or death country is NA
# Then filter for laureates who died in the same country they were born in
whole_life_countries <- lifecycle_countries %>%
  filter(!is.na(birth_country) & !is.na(death_country)) %>%

Question 4: How have laureate birth locations changed over time?

Finally, I explored how birth locations have changed over time. I expected to see a trend where Europe and North America were heavily represented in the early years. After some turning point of globalization I expected to see other continents represented as well.

Code 
birth_place <- nobel_df %>%
  unnest(nobelPrizes, names_sep = "_") %>%
  transmute(
    country = birth.place.countryNow.en,
    continent = birth.place.continent.en,
    year = as.numeric(nobelPrizes_awardYear)
  )
birth_place_clean <- birth_place %>%
  filter(!is.na(continent))

min_year <- min(birth_place_clean$year, na.rm = TRUE)
max_year <- max(birth_place_clean$year, na.rm = TRUE)
all_continents <- sort(unique(birth_place_clean$continent))

cum_cont_df <- birth_place_clean %>%
  group_by(year, continent) %>%
  summarise(count = n(), .groups = "drop") %>%
  complete(year = full_seq(c(min_year, max_year), 1), continent = all_continents, fill = list(count = 0)) %>%
  group_by(continent) %>%
  mutate(cumulative_count = cumsum(count)) %>%
  ungroup()

# 4. Set continent as a factor with a fixed order (Alphabetical or Custom)
cum_cont_df <- cum_cont_df %>%
  mutate(continent = factor(continent, levels = all_continents))
Code 
plot_ly(
  data = cum_cont_df,
  x = ~continent,
  y = ~cumulative_count,
  color = ~continent,
  type = "bar",
  frame = ~year,
  text = ~cumulative_count,
  textposition = "outside"
) %>%
  layout(
    title = list(text = "<b>Cumulative Nobel Laureates by Birth Continent</b>", x = 0.5),
    xaxis = list(
      title = "<b>Birth Continent</b>",
      categoryorder = "array",
      categoryarray = all_continents  # Locks x-axis ordering completely
    ),
    yaxis = list(title = "<b>Total Cumulative Laureates</b>", range = c(0, max(cumulative_df$cumulative_count) * 1.15)),
    showlegend = FALSE
  ) %>%
  animation_opts(frame = 400, transition = 300, redraw = FALSE)

We can see the trend of birth continent year by year in the animated bar plot above. As expected, for the first 40 years, Europe is overwhelmingly represented with North America a distant second. After WWII, other continents begin slowly growing their totals. North America’s award rate increases most significantly to become a less distant second place.. In the last 20 years, Asia specifically has increased it’s representation.
